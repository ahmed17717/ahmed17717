## Featured Projects

### 1. Multilingual RAG System
An AI-powered document question-answering system designed to retrieve information from Arabic and English documents.

- Multilingual document retrieval and question answering.
- Retrieval-augmented generation architecture.
- Focus on retrieval quality and response reliability.

**Technologies:** Python · LangChain · LangGraph · Qdrant · FastAPI · Docker

[View Repository](https://github.com/ahmed17717/mini-rag-app)

---

### 2. Geospatial Climate Prediction
A machine learning project using geospatial data to predict precipitation patterns.

- Data collection and processing using Google Earth Engine.
- Environmental features including temperature, wind speed, and relative humidity.
- Achieved an R² score of 0.9617 on the test set.

**Technologies:** Python · Machine Learning · Google Earth Engine · Pandas · Scikit-learn

---

### 3. Attendify — Smart Hybrid Attendance System
A hybrid attendance application combining Bluetooth Low Energy (BLE) and dynamic QR codes to help reduce proxy attendance.

- Flutter-based student and lecturer interfaces.
- Python/Flask backend with JWT authentication.
- BLE-based attendance detection and time-limited QR verification.

**Technologies:** Flutter · Python · Flask · REST API · BLE · QR Code

[View Frontend Repository](https://github.com/ahmed17717/attendify-frontend)

---

### 4. QueryFlow — Natural Language to Data Queries
A desktop application that helps users explore and analyze geospatial data through natural-language queries.

- LLM-assisted query generation.
- Interactive map visualization using Folium and OpenStreetMap.
- Supports data filtering, JOIN operations, and heatmap exploration.

**Technologies:** Python · CustomTkinter · Folium · OpenStreetMap · LLMs
